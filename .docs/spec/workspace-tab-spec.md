> 2026-07-28 | 資料來源：Playwright 快照 (`page-workspace-tab.yml`, `page-settings.yml`, `page-news-settings.yml`, `page-news-settings-time.yml`)

## 頁面概述

工作區儀表板，整合統計數據、USB 保險箱管理與快速功能選單。Tab 首頁對應路由 `/workspace`。

- **路由檔案**：`app/(tabs)/workspace.tsx`
- **畫面實作**：`client/screens/workspace/index.tsx`

## 3. 新聞追蹤設置 `/news-settings`

- **路由**：`app/news-settings.tsx`
- **畫面**：`client/screens/news-settings/index.tsx`

（完整規格另見 `news-tab-spec.md`）

### Header

```
┌──────────────────────────────────┐
│  ←  新聞追蹤設置                  │
└──────────────────────────────────┘
```

### 關心主題
- 標籤：AI 產業 ×、半導體 ×、金融市場 ×、科技政策 ×
- 輸入框「新增主題…」+ `+` 按鈕

### 摘要重點
- 自動摘要：Switch ON
- 關鍵字高亮：Switch ON
- 摘要長度：簡短 / 中等 / 完整

### 分析 Prompt
- 預設：`請以銷售助理的角度分析這則新聞對我客戶的潛在影響，並提供三個具體的跟進建議。`
- 變數 chips：`{標題}` `{摘要}` `{主題}` `{來源}`
- 💾 儲存設定按鈕

## 4. 時間設置 `/news-settings-time`

- **路由**：`app/news-settings-time.tsx`
- **畫面**：`client/screens/news-settings-time/index.tsx`

### Header

```
┌──────────────────────────────────┐
│  ←  時間設置                      │
└──────────────────────────────────┘
```

### 排程類型
- 每日（激活）/ 每週（chips）

### 每日抓取次數
- 計數器：`−` `1` `+` 次/日
- 說明：每天固定時間抓取一次

### 時區
- 跟隨系統（預設勾選）
- 說明：將使用設備當前時區

### 💾 儲存設定按鈕
