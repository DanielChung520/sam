# 發送 Tab — 功能規格

> 2026-07-28 | 資料來源：Playwright 快照 (`page-broadcast-tab.yml`, `page-broadcast-create.yml`, `page-broadcast-holiday.yml`, `page-broadcast-regular.yml`, `page-broadcast-announce.yml`)

---

## 頁面概述

群發訊息管理功能，涵蓋發送列表與三種群發建立流程（節日群發、定期問安、公告群發）。Tab 首頁對應路由 `/broadcast`。

- **路由檔案**：`app/(tabs)/broadcast.tsx`
- **畫面實作**：`client/screens/broadcast/index.tsx`

---

## 共同規範

### LINE 流量控制

- 每次發送上限 **8 人**
- 建議間隔 ≥ **30 秒**
- 超過 8 人時 UI 鎖定 submit，顯示警告「請減少人數或分批發送」

### 列表更新機制

所有群發建立完成後 `mockBroadcasts.unshift(newItem)`，發送首頁立刻看到最新項目。

## 3. 節日群發 `/broadcast-holiday`

- **路由**：`app/broadcast-holiday.tsx`
- **畫面**：`client/screens/broadcast-holiday/index.tsx`

### Step 指示器

`1.節日 → 2.對象 → 3.AI → 4.圖片 → 5.確認`

### Info Tooltip

> ℹ️ AI 會依每位好友的稱呼、暱稱、職稱自動生成不同祝福語

### Step 1：選擇節日

| 節日 | Emoji |
|------|-------|
| 中秋 | 🥮 |
| 新年 | 🎊 |
| 生日 | 🎂 |
| 開工 | 💼 |
| 端午 | 🐲 |
| 聖誕 | 🎄 |

- 點擊後自動帶入對應預設祝福語 prompt

### Step 2：選擇對象

- 兩種模式（tab 切換）：依標籤篩選 / 指定好友（checkbox 多選）
- 上限 8 人，顯示「已選 X / 8 人」

### Step 3：AI 自動生成

- 「✨ AI 自動生成祝福語」觸發按鈕
- 每位好友獨立生成（使用 honorific、nick、title 變數）
- 可選開關：使用尊稱
- 每位好友卡片含 ↻ 重新生成按鈕
- 整批「重新生成全部」

### Step 4：圖片來源

- 官網訂購（5 個賀卡樣式）
- 自己上傳（裝置 / 相簿 / 拍照）

### Step 5：時間設定

- 節日當天（預設）
- 預約時間（datetime picker）
- 間隔時長：預設 60 秒，最小 30 秒

### Step 6：確認

- 摘要：節日 / 人數 / AI 則數 / 圖片 / 時間 / 間隔
- 確認 → push 進 broadcasts

## 4. 定期問安 `/broadcast-regular`

- **路由**：`app/broadcast-regular.tsx`
- **畫面**：`client/screens/broadcast-regular/index.tsx`

### Step 指示器

`1.對象 → 2.問候 → 3.時間 → 4.確認`

### Info Tooltip

> ℹ️ 定期發送問候，建議每次 ≤ 8 人、間隔 ≥ 30 秒

### Step 1：選擇好友

```
┌────────────────────────────────────┐
│  已選 0 / 8 人                      │
│ ☐ 全選                              │
│ ☐ 好友 #1（張三）                    │
│ ☐ 好友 #2（李四）                    │
│ ☐ 好友 #3（王五）                    │
│ ☐ 好友 #4（陳美玲）                  │
│ ☐ 好友 #5（林大明）                  │
│ ☐ 好友 #6（黃雅婷）                  │
│                                    │
│      [ 下一步 ]                     │
└────────────────────────────────────┘
```

### Step 2：問候類型

- 早安 / 午安 / 晚安（chips 三選一）

### Step 3：發送時間

- **每日**：單一時間 / 多時間
- **每週**：選擇週天（chips）+ 時間
- **自訂**：cron-like（每月幾號 / 幾點）
- 間隔時長設定

### Step 4：確認

- 週期摘要顯示
- 建立 → push broadcasts 標 `recurring: true`

## 5. 公告群發 `/broadcast-announce`

- **路由**：`app/broadcast-announce.tsx`
- **畫面**：`client/screens/broadcast-announce/index.tsx`

### Step 指示器

`1.對象 → 2.內容 → 3.時間 → 4.確認`

### Info Tooltip

> ℹ️ 公告將一次發送給所有選取好友，建議每次 ≤ 8 人

### Step 1：選擇好友

（同定期問安 Step 1 的選人 UI）

### Step 2：公告內容

- 手動輸入（多行 text area + markdown 預覽）
- 貼上外部文字
- 字數統計
- 可加圖片附件

### Step 3：發送時間

- 立即發送 / 預約時間 / 間隔時長

### Step 4：確認

- 內容預覽 + 人數 + 時間 → 建立
