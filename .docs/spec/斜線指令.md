# 斜線指令（/）操作互動規格

> 最後更新：2026-08-04
> 相關實作：`server/src/agent/pipeline.ts`（handleSlash / handleMenuPending）、`server/src/agent/slashMenu.ts`（resolveSlashCommand / buildSlashMenu）
> 互動圖：Mermaid sequence diagram

---

## 1. 總覽

`/` 是**多輪對話**的指令系統：使用者可用「斜線指令」（`/名稱 內容`）或「編號」（`1`、`/3`）呼叫
主 Agent / Sub-Agent / Skill。需要參數但未提供時，進入 pendingArg 狀態提問，等使用者輸入後自動執行。

```
呼叫對象分類：
  主 Agent   → category: orchestrator/planner/reviewer/memory/consultant（自動決策）
  Sub-Agent → category: worker（執行單一任務）
  Skill     → skill registry（process/script/inline executor）
```

## 2. 入口分派（handleMessage）

```mermaid
sequenceDiagram
    autonumber
    participant U as LINE 使用者
    participant W as Webhook
    participant P as PolarisPipeline
    participant M as MenuState(Redis)
    participant S as SlashMenu

    U->>W: 發送文字訊息
    W->>P: handleMessage(text)
    
    alt text === "/" （只看選單）
        P->>M: setMenuState(menuPending: true)
        P->>S: formatSlashMenuText(channelId)
        S-->>P: 選單文字
        P-->>U: 📋 顯示功能選單
    else text === "/new"
        P->>P: handleReset（重設對話）
        P-->>U: 已重新開始
    else text 為 "/編號"（如 /3）
        P->>M: 檢查 menuPending
        P->>P: handleMenuPending("3")
    else text 以 "/" 開頭
        P->>P: handleSlash(text)
    else text 為純數字（如 3）
        P->>S: resolveMenuChoice("3")
        alt 有對應選單項目
            S-->>P: choice
            P->>P: handleSlash("/名稱 內容")
        else 無
            P-->>U: 一般對話處理
        end
    else 一般文字
        P->>P: 意圖引擎/主 Agent
    end
```

## 3. handleSlash 核心流程

```mermaid
sequenceDiagram
    autonumber
    participant U as LINE 使用者
    participant P as PolarisPipeline
    participant S as SlashMenu
    participant A as Agent(主)
    participant D as DelegateToAgent
    participant F as SeaweedFS(產出物)

    U->>P: "/名稱 內容" 或 "/名稱"
    
    alt 是 /？ /help /?
        P->>S: buildSlashMenu(channelId)
        P->>P: buildHelpDoc（markdown → HTML）
        P->>F: 存 HTML 文件
        F-->>P: 分享連結
        P-->>U: 📄 指令說明文件 + 連結
    else 一般指令
        P->>S: resolveSlashCommand(text)
        alt 名稱/id/trigger 未命中
            S-->>P: null
            P->>S: resolveMenuChoice(text)（編號）
            alt 仍無
                P-->>U: ❌ 找不到指令「XX」+ 顯示選單
            end
        end
        S-->>P: target(type, name, remainingArgs)
        
        alt 無參數（remainingArgs 空）
            P->>M: setMenuState(menuPending, pendingArg=name)
            P-->>U: ❓ 請問你要 {name} 做什麼？（輸入 0 取消）
        else type === "skill"
            P->>A: handleMessage("/skillId 內容")
            A-->>P: 執行結果
            P-->>U: 結果
        else type === "sub_agent"
            P->>D: delegateToAgent(name, 內容)
            D-->>P: 委派結果
            P->>P: trySaveArtifact（長文 → HTML）
            P-->>U: 結果 / 📄 標題+連結
        else type === "main_agent"
            P->>A: handleMessage(帶 persona)
            A-->>P: 結果
            P->>P: trySaveArtifact
            P-->>U: 結果 / 📄 標題+連結
        end
    end
```

## 4. 多輪互動：等待參數（pendingArg）

使用者選了需參數的指令（如 `/Spica 主題`）但未給參數 → 進入等待狀態：

```mermaid
sequenceDiagram
    autonumber
    participant U as LINE 使用者
    participant P as PolarisPipeline
    participant M as MenuState(Redis)

    U->>P: "/Spica"
    P->>M: setMenuState(menuPending, pendingArg="Spica")
    P-->>U: ❓ 請問你要 Spica 做什麼？<br/>（輸入內容後自動執行，或輸入 0 取消）

    alt 輸入 "0"
        U->>P: "0"
        P->>M: clear menuPending
        P-->>U: 已取消，請輸入 / 重新查看指令
    else 輸入以 "/" 開頭的新指令
        U->>P: "/write 文章"
        P->>M: clear menuPending
        P->>P: handleMessage(新指令)
    else 輸入一般內容（當作參數）
        U->>P: "寫一篇產品介紹"
        P->>M: clear menuPending
        P->>P: handleSlash("/Spica 寫一篇產品介紹")
        P-->>U: 執行結果
    end
```

## 5. 多輪互動：等待數字選擇（menuPending）

使用者輸入 `/` 後處於選單等待狀態，此時輸入的數字代表選單項目：

```mermaid
sequenceDiagram
    autonumber
    participant U as LINE 使用者
    participant P as PolarisPipeline
    participant M as MenuState(Redis)
    participant S as SlashMenu

    U->>P: "/"（進入選單等待）
    P-->>U: 📋 顯示選單（含編號）
    
    U->>P: "3"（選第 3 項）
    P->>M: 檢查 menuPending=true
    P->>S: resolveMenuChoice("3")
    alt 有對應項目
        S-->>P: choice
        P->>P: handleSlash("/名稱 內容")
        P-->>U: 執行結果
    else 無（編號超出範圍）
        P-->>U: ❌ 沒有收到指令（3）<br/>請繼續輸入數值，或 0 結束
    end

    alt 輸入 "0"
        U->>P: "0"
        P->>M: clear menuPending
        P-->>U: 已結束，請輸入 / 重新查看指令
    else 輸入非數字
        U->>P: "你好"
        P-->>U: ❌ 沒有收到指令<br/>請輸入數值，或 0 結束（重新顯示選單）
    end
```

## 8. 狀態機（MenuState）

```mermaid
stateDiagram-v2
    [*] --> IDLE
    IDLE --> MENU_PENDING: 輸入 "/"
    IDLE --> PENDING_ARG: 選需參數指令（無參數）
    MENU_PENDING --> IDLE: 輸入 "0"
    MENU_PENDING --> EXECUTING: 數字選擇命中
    MENU_PENDING --> MENU_PENDING: 無效輸入（重新顯示選單）
    PENDING_ARG --> IDLE: 輸入 "0"
    PENDING_ARG --> EXECUTING: 輸入參數內容
    PENDING_ARG --> REDISPATCH: 輸入 "/" 開頭（新指令）
    REDISPATCH --> EXECUTING
    EXECUTING --> IDLE: 完成
```

## 9. 互動重點整理

| 情境 | 使用者輸入 | 系統行為 |
|------|-----------|---------|
| 顯示選單 | `/` | 設 menuPending，顯示功能選單 |
| 說明文件 | `/？` `/help` `/？` | 產生 HTML 說明文件存 SeaweedFS，回標題+連結 |
| 直接執行 | `/名稱 內容` | resolveSlashCommand → 依 type 執行 |
| 需參數提問 | `/名稱`（無內容）| 設 pendingArg，問「請問你要 X 做什麼？」 |
| 多輪補參數 | 輸入內容（pendingArg 中）| 自動補成 `/名稱 內容` 執行 |
| 編號選擇 | `1` `2` `/3` | resolveMenuChoice → handleSlash |
| 取消等待 | `0` | 清除 menuPending / pendingArg |
| 找不到指令 | `/未知` | 回「找不到指令」+ 重新顯示選單 |
