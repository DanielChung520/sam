## 3. 掃一掃 `/scan`

- **路由**：`app/scan.tsx`
- **畫面**：`client/screens/scan/index.tsx`

### Header

```
┌──────────────────────────────────┐
│  ✕  掃一掃                       │
└──────────────────────────────────┘
```

- **返回按鈕**：✕（關閉 icon，非 ← 箭頭）

### 掃描結果範例

```
┌──────────────────────────────────────┐
│                                      │
│              林志玲                    │
│              模特兒                   │
│                                      │
│            [ 加入 ]                   │
└──────────────────────────────────────┘
```

- 顯示掃描到的名片資訊：姓名 + 職稱
- 加入按鈕：將該名片加入名片夾

## 導覽路徑

```
好友漢堡選單 / 工作區快速選單
  ├── 名片夾(/card-holder)
  │       ├── 掃描名片 → 掃一掃(/scan)
  │       └── 卡片詳情（尚無獨立路由）
  └── 賀卡/問候庫(/greeting-cards)
          └── 賀卡點擊（尚無編輯/預覽路由）
```
