# SAM 群發功能規格

> 日期：2026-07-28
> 版本：v1
> 範圍：發送 tab 下的 3 種子功能

## 共同規範

- **每次發送上限 8 人**：避免 LINE 流量控制
- **LINE 流量控制安全值**：官方建議每分鐘 ≤ 20 則群發，本系統預設每次 ≤ 8 人 + 可設定間隔
- **所有頁面都參考 `broadcast-create` 的 3-step flow**（選擇對象 → 編輯內容 → 確認）
- **所有頁面建完後都會 push 進 `mockBroadcasts` 列表**，預設頁（發送首頁）就能看到

---

## 1. 節日群發 `screens/broadcast-holiday`

**目的**：在指定節日向客戶發送節日祝福，圖文並茂。

### Step 1：選擇節日
- 節日清單（chips / 下拉）：
  - 中秋、新年、生日、開工、端午、聖誕
  - 來源：從 `greetingTemplates` mock 動態載入
- 選完節日自動帶出預設祝福語 prompt

### Step 2：選擇朋友
- 兩種模式（tab 切換）：
  - **依標籤篩選**（VIP / 高意向 / 決策者 / 沉睡 / 中等 / 自訂）
  - **指定好友**（checkbox 多選清單）
- **每次發送上限 8 人**（超過 8 人顯示警告，需分批）
- 顯示已選人數：「已選 X / 8 人」

### Step 3：AI 自動生成祝福語
- **核心變更**：不是制式模板，是 AI 為**每位好友**獨立生成
- 觸發按鈕：「✨ AI 自動生成祝福語」
- **每位好友的變數**：
  - `尊稱`（如「張經理」，從 `honorific` 欄位）
  - `暱稱`（如「三哥」，從 `nick` 欄位）
  - `職稱`（如「業務經理」，從 `title` 欄位）
- **可選開關**：
  - ☑ 使用尊稱（ON 時用 honorific，否則用 name）
- **生成結果**：
  - 模擬 1.2 秒 AI 推理
  - 每位好友一張卡片，顯示頭像 / 姓名 / 職稱 / 尊稱暱稱標籤 / 祝福語內容
  - 每張卡片右上 ↻ 鈕可**單獨重新生成**該則
  - 整批「重新生成全部」按鈕
- **場景多樣性**：每節日預設 4 種不同變化的模板，AI 從中隨機選一個給每位好友
  - 中秋：4 種（傳統、月圓、收穫、秋風）
  - 新年：4 種（鴻圖、揮別、回首、辭舊）
  - 生日：4 種（感謝、記得、特別、珍貴）
  - 開工：4 種（大吉、新程、興旺、努力）
  - 端午：4 種（安康、飄香、傳承、五月）
  - 聖誕：4 種（Merry、歲末、分享、平安）
- **為什麼不是制式**：避免「親愛的客戶，中秋快樂」這種罐頭訊息感，針對職稱/暱稱客製

### Step 4：圖片來源
- 兩種選項：
  - **官網訂購**（點選模板庫，列舉 5 個賀卡樣式）
  - **自己上傳**（從裝置/相簿/拍照上傳）
- 註明「官網訂購」的字樣 + 連結到官網
- 顯示預覽縮圖

### Step 5：時間設定
- 節日當天發送（預設）
- 預約時間（datetime picker）
- **間隔時長**（輸入框，單位：秒/分鐘）
  - 預設：60 秒
  - 最小：30 秒
  - 說明：每則間隔這麼長時間發送

### Step 6：確認 + 建立
- 預覽發送內容（含 AI 個人化則數）
- 摘要：節日 / 人數 / AI 個人化則數 / 圖片 / 時間 / 間隔
- 確認 → push 進 broadcasts

## 2. 定期問安 `screens/broadcast-regular`

**目的**：設定週期性問候，可設定每日 / 每週 / 自訂時段。

### Step 1：選擇朋友
- 同節日群發 Step 2

### Step 2：問候類型
- 早安 / 午安 / 晚安（chips 互斥，三選一）
- 預設 prompt 自動帶入該時段問候語

### Step 3：問候 prompt
- 預設 prompt：依時段從 `greetingTemplates` 帶入
- 可編輯
- 變數替換同節日群發

### Step 4：發送時間（重點）
- 每日
  - 單一時間（time picker）
  - 多時間（每日 2-3 次）
- 每週
  - 選擇週天（多選 chips）
  - 每週幾點
- 自訂
  - 完整 cron-like 設定（每月幾號 / 幾點）
- 間隔時長（同節日群發）

### Step 5：確認
- 週期摘要
- 建立 → push 進 broadcasts 標 `recurring: true`

## 3. 公告群發 `screens/broadcast-announce`

**目的**：發送公司公告 / 產品發布 / 重要通知，純文字為主。

### Step 1：選擇朋友
- 同上

### Step 2：公告內容
- **兩種模式**（tab 切換）：
  - **手動輸入**：多行 text area，支援 markdown 預覽
  - **貼上**：貼上外部文字（保留格式）
- 字數統計
- 預覽（模擬手機聊天視窗樣式）
- 可加圖片附件（從官網/上傳）

### Step 3：發送時間
- 立即發送
- 預約時間
- 間隔時長（同節日群發）

### Step 4：確認
- 內容預覽
- 人數 / 時間
- 建立

---

## 共同：建立後的行為

1. **mockBroadcasts.unshift(newItem)** 讓預設頁（發送首頁）立刻看到
2. 預設頁的 broadcast list 應顯示：
   - 節日群發：status 顯示「排程」、title 帶節日名
   - 定期問安：status 顯示「週期」、title 帶時段（早/午/晚安）
   - 公告群發：status 顯示「已完成」或「排程」、title 帶前 20 字
3. 每筆點擊可看詳情（status, scheduledAt, template, sent/total）

## 共同：LINE 流量控制提醒

- 頁面 step 1 顯示友善提示：「為避免觸發 LINE 流量限制，建議每次發送 ≤ 8 人，間隔 ≥ 30 秒」
- 若超過 8 人，UI 鎖定 submit 按鈕，顯示「請減少人數或分批發送」
