# 好友 Tab — 功能規格

> 2026-07-28 | 資料來源：Playwright 快照 (`page-friends-tab.yml`, `page-friend-detail.yml`, `page-add-friend.yml`, `page-sync-friends.yml`)

---

## 頁面概述

通訊錄管理功能，涵蓋好友列表檢視、篩選搜尋、詳情頁、加入好友、同步好友及名片夾。Tab 首頁對應路由 `/friends`。

- **路由檔案**：`app/(tabs)/friends.tsx`
- **畫面實作**：`client/screens/friends/index.tsx`

---

## 1. 好友列表 `/friends`

### Header

```
┌──────────────────────────────────┐
│  好友                          ⋯ │
│  USB 已連接 · 地端保護模式        │
│  🔍  搜尋好友...                  │
│  全部  VIP  高意向  決策者  沉睡   │
└──────────────────────────────────┘
```

- **Title**：`好友`，字級 22px、weight 600
- **右側按鈕**：`⋯` 更多（漢堡選單 toggle）
- **USB 狀態徽章**：顯示於 header 下方
- **搜尋列**：放大鏡 icon + TextInput `placeholder="搜尋好友..."`
- **標籤篩選**：水平滾動 chips — 全部 / VIP / 高意向 / 決策者 / 沉睡
  - 激活 chip：primary 色背景 + 白色文字
  - 未激活：`bgInput` 色背景 + `textSecondary` 色文字

### 漢堡選單

| 項目 | 圖示 | 路由 | 顏色 |
|------|------|------|------|
| 同步好友 | 🔄 | `/sync-friends` | info (藍) |
| 添加好友 | 👤+ | `/add-friend` | primary (綠) |
| 掃一掃 | 📱 | `/scan` | sky (天藍) |
| 名片夾 | 🪪 | `/card-holder` | accent (琥珀) |

## 2. 好友詳情 `/friend-detail`

- **路由**：`app/friend-detail.tsx`
- **畫面**：`client/screens/friend-detail/index.tsx`

### 狀態

Playwright 擷取時顯示 `<progressbar>` — 頁面為動態載入，透過路由參數 `contactId` 取得資料。

### 導覽

- Header 包含返回箭頭 `←` + 好友姓名（動態）
- 從好友列表點擊卡片時傳入 `{ contactId }` 參數

## 3. 加入好友 `/add-friend`

- **路由**：`app/add-friend.tsx`
- **畫面**：`client/screens/add-friend/index.tsx`

### Header

```
┌──────────────────────────────────┐
│  ←  加入好友                  搜尋 │
└──────────────────────────────────┘
```

### 加入方式（6 宮格）

| 圖示 | 標題 | 說明 |
|------|------|------|
| 📩 | 行動條碼 | 掃描好友的條碼 |
| 📱 | 搖一搖 | 同時搖手機即可互加 |
| @ | LINE ID | 透過 ID 搜尋 |
| 🔗 | 邀請連結 | 產生專屬邀請網址 |
| 👥 | 手機聯絡人 | 從手機通訊錄加入 |
| 📍 | 附近的人 | 開啟定位加入周遭用戶 |
