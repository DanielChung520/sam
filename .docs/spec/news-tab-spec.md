# 新聞 Tab — 功能規格

> 2026-07-28 | 資料來源：Playwright 快照 (`page-news-tab.yml`)

---

## 頁面概述

新聞追蹤功能，讓用戶瀏覽分類新聞並設定追蹤主題。頁面為 Tab 首頁之一，對應路由 `/news`。

- **路由檔案**：`app/(tabs)/news.tsx`
- **畫面實作**：`client/screens/news/index.tsx`

---

## Header

```
┌──────────────────────────────────┐
│  新聞追蹤                       ⚙️ │
└──────────────────────────────────┘
```

- **Title**：`新聞追蹤`，字級 22px、weight 600
- **右側按鈕**：齒輪 icon（`⚙️`），點擊開啟漢堡選單
  - 漢堡選單選項：新聞追蹤設置 → 導航至 `/news-settings`
- **導航**：無返回按鈕（Tab 首頁無需返回）

---

## 分類篩選器

水平排列的 Filter chips，點擊切換新聞列表：

| Filter | 狀態 |
|--------|------|
| 全部 | 預設激活 |
| 今日焦點 | 可選 |
| 產業 | 可選 |
| 科技 | 可選 |

- 激活的 chip 使用 primary 色背景 + 白色文字
- 未激活的 chip 使用 `bgInput` 色背景 + `textSecondary` 色文字

---

## 新聞列表

新聞卡片列表，每筆 `cursor=pointer`，點擊可看詳情（目前於 App 內嵌顯示，非獨立詳情頁）。

### 新聞項目結構

```
┌────────────────────────────────────┐
│ [今日焦點]                   2 小時前 │ ← 分類標籤 + 來源·時間
│ 台灣央行利率決策：維持不變             │ ← 標題（粗體）
│ 央行理監事會議決議維持利率不變...       │ ← 摘要（2行截斷）
└────────────────────────────────────┘
```

## 子頁面

### 新聞追蹤設置 `/news-settings`

- **路由**：`app/news-settings.tsx`
- **畫面**：`client/screens/news-settings/index.tsx`

#### 關心主題
- 已設定主題標籤（可刪除 ×）：AI 產業、半導體、金融市場、科技政策
- 輸入框「新增主題…」+ 添加按鈕

#### 摘要重點
- 自動摘要：Switch（預設開啟）
- 關鍵字高亮：Switch（預設開啟）
- 摘要長度選擇：簡短 / 中等 / 完整（chips）

#### 分析 Prompt
- 文字編輯框，預設內容：「請以銷售助理的角度分析這則新聞對我客戶的潛在影響，並提供三個具體的跟進建議。」
- 變數插入 chips：`{標題}` `{摘要}` `{主題}` `{來源}`
- 儲存設定按鈕

### 時間設置 `/news-settings-time`

- **路由**：`app/news-settings-time.tsx`
- **畫面**：`client/screens/news-settings-time/index.tsx`

#### 排程類型
- 每日 / 每週（chips 二選一）

#### 每日抓取次數
- 計數器：`−` `1` `+`（次/日）
- 說明文字：「每天固定時間抓取一次」

#### 時區
- 跟隨系統（預設勾選）
- 說明：「將使用設備當前時區」

#### 儲存設定按鈕
