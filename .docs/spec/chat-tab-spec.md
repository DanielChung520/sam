# 聊天 Tab — 功能規格

> 2026-07-28 | 資料來源：Playwright 快照 (`page-chat-tab.yml`, `page-chat-detail.yml`, `page-chat-history.yml`, `page-ai-chat.yml`)

---

## 頁面概述

即時對話管理功能，涵蓋聊天列表、聊天詳情、歷史記錄與 AI 銷售助理。Tab 首頁對應路由 `/`（index）。

- **路由檔案**：`app/(tabs)/index.tsx`
- **畫面實作**：`client/screens/chats/index.tsx`

---

## 1. 聊天列表 `/` (Chat Tab)

### Header

```
┌──────────────────────────────────┐
│  對話                   🕐  🔍  │
│  USB 已連接 · 地端保護模式        │
└──────────────────────────────────┘
```

- **Title**：`對話`，字級 22px、weight 600
- **右側按鈕組**：
  - 🕐 `clock-rotate-left`：導航至歷史記錄 `/chat-history`
  - 🔍 `magnifying-glass`：搜尋（當前未綁定路由，placeholder）
- **USB 狀態徽章**：顯示於 header 下方

### 聊天卡片列表

每張卡片 `cursor=pointer`，點擊導航至 `/chat-detail`。

## 2. 聊天詳情 `/chat-detail`

- **路由**：`app/chat-detail.tsx`
- **畫面**：`client/screens/chat-detail/index.tsx`

### 狀態

Playwright 擷取時顯示 `<progressbar>` — 頁面需動態載入歷史訊息，透過路由參數 `contactId`、`contactName` 取得資料。

### 導覽

- Header 包含返回箭頭 `←` + 聯絡人名稱（動態）
- 從聊天列表點擊卡片時傳入 `{ contactId, contactName }`

## 4. AI 私人聊天室 `/ai-chat`

- **路由**：`app/ai-chat.tsx`
- **畫面**：`client/screens/ai-chat/index.tsx`

### Header

```
┌──────────────────────────────────┐
│  ←  🤖  AI 私人聊天室            │
└──────────────────────────────────┘
```

**AI 訊息（09:00）**
> 🤖 你好！我是你的 AI 銷售助理。我可以幫你分析客戶互動、生成回覆建議、或回答任何銷售相關問題。

```
┌──────────────────────────────────┐
│  問 AI 任何銷售問題...         📤 │  ← TextInput + Send 按鈕
└──────────────────────────────────┘
```
